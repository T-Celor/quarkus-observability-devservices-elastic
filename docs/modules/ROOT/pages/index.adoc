= Observability Dev Services Elastic
:description: Quarkiverse extension that provisions an Elastic observability stack for Quarkus dev and test modes.

The `quarkus-observability-devservices-elastic` extension starts:

- Elasticsearch
- Kibana
- Elastic APM Server
- OpenTelemetry Collector

and publishes a default `quarkus.otel.exporter.otlp.endpoint` for the host OTLP gRPC receiver.

== Installation

[source,xml]
----
<dependency>
  <groupId>io.quarkiverse.observability</groupId>
  <artifactId>quarkus-observability-devservices-elastic</artifactId>
  <version>${project.version}</version>
</dependency>
----

== Orchestration modes

Mode selection follows Quarkus Dev Services conventions:

- `quarkus.compose.devservices.enabled=true` -> Compose Dev Services
- otherwise -> Testcontainers

Compose file precedence in Compose mode:

- `quarkus.compose.devservices.files` from the consuming application
- `quarkus.observability.devservices.elastic.compose.files`
- extension-generated compose file under `target/quarkus-devservices/elastic/compose-devservices.yml`

In compose mode, this extension keeps orchestration on Compose Dev Services (no Testcontainers fallback).

== Configuration

Main prefix: `quarkus.observability.devservices.elastic`.

Important keys:

- `enabled` (default `true`)
- `reuse` (default `false`, Testcontainers mode)
- `elasticsearch-image` (default `elasticsearch:9.5.5`)
- `kibana-image` (default `kibana:9.5.5`)
- `apm-server-image` (default `elastic/apm-server:9.5.5`)
- `otel-collector-image` (default `otel/opentelemetry-collector-contrib:0.164.0`)
- `otel-collector-config` (optional custom collector YAML file)
- `elasticsearch-port` (default `9200`)
- `kibana-port` (default `5601`)
- `apm-server-port` (default `8200`)
- `otlp-grpc-port` (default `4317`)
- `otlp-http-port` (default `4318`)
- `compose.files` (optional compose file path)
- `compose.project-name` (default `observability-elastic`)

Only host-published ports are configurable. Internal service-to-service links stay fixed:

- Kibana -> `http://elasticsearch:9200`
- APM Server -> `http://elasticsearch:9200` and `http://kibana:5601`
- OpenTelemetry Collector -> `http://apm-server:8200`

== Testcontainers port policy

- Reuse the running stack only when all expected host ports are occupied by matching images (atomic full-stack reuse).
- Fail fast when only part of the expected stack is already running on matching-image ports.
- Fail fast when an explicitly configured port is already used by a different process/image.
- Auto-allocate a new free host port when a non-explicit default port is unavailable.

== Compose mode example

[source,yaml]
----
quarkus:
  compose:
    devservices:
      enabled: true
      project-name: projectname
  observability:
    devservices:
      elastic:
        enabled: true
        compose:
          files: ./src/main/compose/compose-devservices.yml
----

If custom compose files are used, keep published host ports aligned with `quarkus.observability.devservices.elastic.*-port` so the generated OTLP endpoint remains correct.

== Testing

The extension provides:

- JVM mode test (`@QuarkusTest`)
- packaged mode test (`@QuarkusIntegrationTest`)

JVM tests validate stack endpoint reachability and OTLP endpoint publication. Packaged mode keeps config bootstrap validation without forcing container assertions.
